# Contact Page (Static)

A small static front-end project for a configurable contact page.

## Structure
- `index.html` Entry page
- `css/styles.css` Styles
- `js/config.js` All configurable content and theme
- `js/app.js` Render logic
- `assets/` Reserved for images or icons

## Quick Start
Open `index.html` directly in a browser.

## Local Preview
Run a static server (Node.js required):

```bash
npm run dev
```

## Configuration
Edit `js/config.js` to update text, theme colors, and contact buttons. Use the `show` flags to toggle visibility.
